# Satis Deployment on Coolify

Deploy Satis using Docker on Coolify with automated rebuilds and webhook support.

## Quick Start

**Recommended Image:** `rebelinblue/satis` (includes auto-rebuild via cron and webhooks)

**Alternative:** Official `composer/satis` (manual rebuilds only)

## Deployment with rebelinblue/satis

### docker-compose.yml

```yaml
services:
  satis:
    image: rebelinblue/satis:latest
    container_name: satis
    ports:
      - "80:80"
    volumes:
      - ./config/satis.json:/satis/satis.json:ro
      - ./output:/satis/output
      - ./ssh:/root/.ssh:ro
      - ./htpasswd:/etc/nginx/.htpasswd:ro
    environment:
      # Rebuild schedule (cron syntax)
      - CRON_SCHEDULE=0 */6 * * *

      # Webhook secret for git push triggers
      - WEBHOOK_SECRET=${WEBHOOK_SECRET}

      # Optional: Composer auth for private packagist
      - COMPOSER_AUTH=${COMPOSER_AUTH}
    restart: unless-stopped
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost/packages.json"]
      interval: 30s
      timeout: 10s
      retries: 3
```

### Directory Structure

```
satis/
├── docker-compose.yml
├── config/
│   └── satis.json
├── ssh/
│   ├── id_ed25519
│   ├── id_ed25519.pub
│   └── known_hosts
├── htpasswd/
│   └── .htpasswd
└── output/                    # Generated by Satis
    ├── index.html
    ├── packages.json
    └── dist/
```

## satis.json Configuration

### Basic Configuration

```json
{
  "name": "Agency Private Packages",
  "homepage": "https://packages.youragency.com",
  "description": "Private Composer repository for WordPress themes and plugins",

  "repositories": [
    {
      "type": "vcs",
      "url": "git@github.com:agency/base-theme.git"
    },
    {
      "type": "vcs",
      "url": "git@github.com:agency/utilities-plugin.git"
    }
  ],

  "require-all": true,

  "archive": {
    "directory": "dist",
    "format": "zip",
    "skip-dev": true,
    "checksum": true
  },

  "output-html": true
}
```

### Advanced Configuration

```json
{
  "name": "Agency Private Packages",
  "homepage": "https://packages.youragency.com",
  "description": "Private repository with all agency WordPress packages",

  "repositories": [
    {
      "type": "vcs",
      "url": "git@github.com:agency/base-theme.git",
      "name": "agency/base-theme"
    },
    {
      "type": "vcs",
      "url": "git@github.com:agency/utilities.git",
      "name": "agency/utilities"
    },
    {
      "type": "composer",
      "url": "https://wpackagist.org"
    }
  ],

  "require-all": true,
  "require-dependencies": true,
  "require-dev-dependencies": false,

  "archive": {
    "directory": "dist",
    "format": "zip",
    "skip-dev": true,
    "prefix-url": "https://cdn.youragency.com/packages",
    "whitelist": ["agency/*"],
    "checksum": true
  },

  "abandoned": {
    "agency/old-theme": true,
    "agency/legacy-plugin": "agency/new-plugin"
  },

  "providers": false,
  "output-html": true,
  "output-dir": "output"
}
```

**Key Options:**

- **`require-all: true`** - Automatically index all tags and branches from all repos
- **`require-dependencies: true`** - Include dependencies of your packages (useful if packages depend on Packagist packages)
- **`archive.skip-dev: true`** - Don't create archives for `dev-*` branch versions
- **`archive.prefix-url`** - Serve archives from CDN (sync `output/dist/` after build)
- **`providers: false`** - Generate single `packages.json` (use `true` for 100+ packages)

## SSH Key Setup

### Generate Deploy Key

```bash
# Generate Ed25519 key (recommended)
ssh-keygen -t ed25519 -C "satis@youragency.com" -f ./ssh/id_ed25519 -N ""

# Or RSA (if Ed25519 not supported)
ssh-keygen -t rsa -b 4096 -C "satis@youragency.com" -f ./ssh/id_rsa -N ""
```

### Add to GitHub/GitLab

**GitHub:**
1. Repository → Settings → Deploy keys → Add deploy key
2. Paste public key (`cat ssh/id_ed25519.pub`)
3. Title: "Satis Server"
4. **Do NOT** check "Allow write access" (read-only is safer)

**GitLab:**
1. Repository → Settings → Repository → Deploy Keys
2. Same process as GitHub

### Set Permissions

```bash
chmod 700 ssh/
chmod 600 ssh/id_ed25519
chmod 644 ssh/id_ed25519.pub
```

### Test SSH Connection

```bash
docker exec -it satis ssh -T git@github.com
# Expected: "Hi! You've successfully authenticated..."
```

## HTTP Basic Auth Setup

### Create .htpasswd

```bash
# Install htpasswd (if needed)
# Ubuntu/Debian: apt install apache2-utils
# macOS: already installed

# Create password file
htpasswd -c htpasswd/.htpasswd composer

# Add more users
htpasswd htpasswd/.htpasswd developer
```

**Permissions:**
```bash
chmod 644 htpasswd/.htpasswd
```

### Verify Authentication

```bash
# Test without auth (should fail)
curl -I https://packages.youragency.com/packages.json

# Test with auth (should succeed)
curl -u composer:password -I https://packages.youragency.com/packages.json
```

## Environment Variables

Create `.env` file:

```bash
# Webhook secret for automated rebuilds
WEBHOOK_SECRET=your-random-secret-string-here

# Optional: Composer auth for private packagist
COMPOSER_AUTH='{"github-oauth": {"github.com": "your-github-token"}}'
```

**Generate webhook secret:**
```bash
openssl rand -hex 32
```

## Build Process

### Manual Build

```bash
# Enter container
docker exec -it satis bash

# Run build
/satis/bin/satis build /satis/satis.json /satis/output -vvv

# Or from host
docker exec satis /satis/bin/satis build /satis/satis.json /satis/output
```

### Automated Rebuild (Cron)

**Default:** Runs every 6 hours (`0 */6 * * *`)

**Custom Schedule:**
```yaml
environment:
  - CRON_SCHEDULE=0 */3 * * *   # Every 3 hours
  - CRON_SCHEDULE=0 0 * * *     # Daily at midnight
  - CRON_SCHEDULE=*/30 * * * *  # Every 30 minutes
```

**Cron Syntax:**
```
┌───────────── minute (0 - 59)
│ ┌───────────── hour (0 - 23)
│ │ ┌───────────── day of month (1 - 31)
│ │ │ ┌───────────── month (1 - 12)
│ │ │ │ ┌───────────── day of week (0 - 6) (Sunday to Saturday)
│ │ │ │ │
│ │ │ │ │
* * * * *
```

### Webhook Rebuild

**Webhook URL:**
```
https://packages.youragency.com/webhook?secret=your-webhook-secret
```

**GitHub Setup:**
1. Repository → Settings → Webhooks → Add webhook
2. Payload URL: (webhook URL above)
3. Content type: `application/json`
4. Events: `Just the push event`
5. Active: ✓

**GitLab Setup:**
1. Repository → Settings → Webhooks
2. URL: (webhook URL above)
3. Secret token: `your-webhook-secret`
4. Trigger: `Push events`, `Tag push events`
5. Enable: ✓

**Test Webhook:**
```bash
curl -X POST "https://packages.youragency.com/webhook?secret=your-webhook-secret"
```

## CDN Integration (Optional)

### Option A: Sync to External CDN

**After each build, rsync archives:**
```bash
#!/bin/bash
# sync-to-cdn.sh

rsync -avz --delete \
  /path/to/satis/output/dist/ \
  user@cdn-server:/var/www/packages/dist/
```

**satis.json:**
```json
{
  "archive": {
    "directory": "dist",
    "prefix-url": "https://cdn.youragency.com/packages"
  }
}
```

### Option B: CloudFlare in Front

**Coolify → CloudFlare DNS:**
```
packages.youragency.com → CNAME → your-coolify-domain
```

**CloudFlare Settings:**
- Cache Level: Standard
- Browser Cache TTL: 4 hours
- Always Online: On
- Page Rules: Cache Everything for `*.zip`, `packages.json`

## Coolify Deployment Steps

### 1. Create New Service

- Type: Docker Compose
- Name: `satis`
- Repository: (upload docker-compose.yml or use git)

### 2. Configure Volumes

Mount these paths:
- `./config/satis.json` → `/satis/satis.json` (read-only)
- `./ssh` → `/root/.ssh` (read-only)
- `./htpasswd/.htpasswd` → `/etc/nginx/.htpasswd` (read-only)
- `./output` → `/satis/output` (read-write)

### 3. Set Environment Variables

In Coolify environment tab:
- `WEBHOOK_SECRET`: (your webhook secret)
- `CRON_SCHEDULE`: `0 */6 * * *`

### 4. Configure Domain

- Add domain: `packages.youragency.com`
- Enable SSL: ✓ (Let's Encrypt)

### 5. Deploy

Click "Deploy" and monitor logs:
```bash
# Watch build process
docker logs -f satis
```

## Verification Checklist

After deployment:

- [ ] `https://packages.youragency.com` shows HTML index
- [ ] `https://packages.youragency.com/packages.json` returns JSON
- [ ] HTTP Basic Auth works (`curl -u user:pass`)
- [ ] SSH keys work (test git clone inside container)
- [ ] Webhook triggers rebuild (check GitHub/GitLab delivery logs)
- [ ] Cron runs on schedule (`docker logs satis` shows cron output)

## Troubleshooting

### Build Fails with "Permission Denied"

**Symptom:** `Could not clone git@github.com:...`

**Fix:**
```bash
# Check SSH key permissions
ls -la ssh/

# Should be:
# drwx------ ssh/
# -rw------- ssh/id_ed25519
# -rw-r--r-- ssh/id_ed25519.pub

chmod 700 ssh/
chmod 600 ssh/id_ed25519
```

### Webhook Returns 403

**Symptom:** Webhook fails with `Invalid secret`

**Fix:**
```bash
# Verify secret matches
echo $WEBHOOK_SECRET

# Test webhook manually
curl -X POST "https://packages.youragency.com/webhook?secret=$WEBHOOK_SECRET"
```

### Archives Not Generated

**Symptom:** `packages.json` exists but `dist/` is empty

**Fix:**
Check `satis.json` has `archive` section:
```json
{
  "archive": {
    "directory": "dist",
    "format": "zip"
  }
}
```

Verify output directory is writable:
```bash
docker exec satis ls -la /satis/output/
# Should show dist/ directory
```

### Memory Errors During Build

**Symptom:** `Allowed memory size exhausted`

**Fix:**
Increase PHP memory in `docker-compose.yml`:
```yaml
environment:
  - PHP_MEMORY_LIMIT=512M
```

Or for very large repos:
```yaml
environment:
  - PHP_MEMORY_LIMIT=1G
```

## Maintenance

### Update Satis Image

```bash
docker-compose pull
docker-compose up -d
```

### Rotate SSH Keys

```bash
# Generate new key
ssh-keygen -t ed25519 -f ./ssh/id_ed25519_new

# Add to GitHub/GitLab
cat ./ssh/id_ed25519_new.pub

# Replace old key
mv ./ssh/id_ed25519 ./ssh/id_ed25519.old
mv ./ssh/id_ed25519_new ./ssh/id_ed25519

# Restart container
docker-compose restart
```

### Backup

**Backup these directories:**
```bash
# Configuration
tar -czf satis-config-$(date +%Y%m%d).tar.gz config/ ssh/ htpasswd/

# Optional: Output (regenerable, but saves rebuild time)
tar -czf satis-output-$(date +%Y%m%d).tar.gz output/
```
